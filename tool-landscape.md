# AI Testing Tool Landscape

| Category | Tool | One-line use case |
| --- | --- | --- |
| End-to-end browser automation | Playwright | Automate browser interactions and verify UI behavior end to end. |
| Visual regression testing | Applitools | Detect visual UI changes with AI-assisted screenshot comparison. |
| Self-healing test automation | ZeroStep | Keep browser tests running by automatically resolving changed locators. |
| Self-healing test automation | AgentQL | Use semantic selectors to find UI elements even when the DOM changes. |
| Test generation / AI-assisted authoring | GitHub Copilot for Testing | Help generate and refine Playwright tests from natural language. |
| Accessibility testing | axe | Check web pages for accessibility issues automatically. |
| Cross-browser testing | BrowserStack | Run tests across many browsers and devices in the cloud. |
